# 上传草图分析规程

由当前多模态 GPT 直接查看用户上传的图片。不得把图片交给本地 OCR、OpenCV、轮廓跟踪或自动矢量化程序。

## 先观察，再推断

输出四组信息：

1. **可见事实**：视图数量、清晰可读的标注、孔数、中心线、对称符号、剖面线。
2. **几何解释**：哪些轮廓属于同一实体，虚线是否表示隐藏特征，各视图如何对应。
3. **不确定项**：模糊数字、遮挡、自由手绘造成的非圆或不平行，分别标记高/中/低置信度。
4. **建模假设**：对称、等距、同轴、等径等假设；必须能够通过参数修改。

## 尺度规则

- 像素长度不是实际尺寸。
- 至少需要一个真实尺寸、已知标准件，或明确的比例尺。
- 单视图不能可靠确定厚度时，询问厚度；如果用户说可自行决定，则把厚度做成参数并记录假设。
- 对电机、轴承、风扇等接口，图片外形不能替代零件号或数据表。

## 何时必须追问

- 不同解释会改变孔是否贯穿、实体数量或装配关系。
- 缺少基准尺寸，无法建立实际尺度。
- 配合公差、轴径、孔距或安装面不确定。
- 两个视图互相矛盾。

倒角、圆角和外观细节若不影响装配，可先省略并明确说明。
